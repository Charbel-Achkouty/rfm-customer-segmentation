# Data

This project uses the **Online Retail** dataset (UK-based online store, 2010-2011).

Download one of these and place the file in this folder:

- UCI Machine Learning Repository: "Online Retail" (`Online Retail.xlsx`)
- Kaggle: search "Online Retail" (`data.csv`)
- "Online Retail II" (`online_retail_II.xlsx`) also works

Then run:

```bash
python main.py --data "data/Online Retail.xlsx"
```

The raw file is git-ignored because of its size.
